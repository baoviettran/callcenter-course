The Big Picture

A self-hosted call center platform — seven programs, three protocols, one click.

📞
The green button

Every day, someone clicks a green button in a browser tab, hears a ring, and talks to a customer. That single click crosses seven programs and three protocols in under a second. This course follows that click.

This platform is a self-hosted call center built on top of FreeSWITCH and FusionPBX. Instead of one big box, it is a team of specialized programs working together.

Why does this matter? When someone says "calls are dropping," your first job is knowing which program to look at. This module gives you that map.

The Journey of One Call

Think of this platform as an airport. The agent is the traveler, the softphone is their boarding-pass app, Kamailio is the security checkpoint, FreeSWITCH is the terminal, and FusionPBX is the management office.

Seeing It in Code

The "terminal" is just containers on a server. Here is how it is defined.

CODE 

services:
  postgres:
    image: luongld/postgres:14
    container_name: postgres_140
  pbx:
    image: luongld/pbx:1.10.8
    container_name: pbx_1108
PLAIN ENGLISH

Define the services (programs) that make up the terminal...

PostgreSQL — the filing cabinet where call records are stored...

Use the Docker image called "luongld/postgres" version 14...

Name this container "postgres_140" so we can find it later...

FreeSWITCH + FusionPBX — the actual telephony engine...

Use the Docker image called "luongld/pbx" version 1.10.8...

Name this container "pbx_1108"

And here is how the browser softphone registers itself — the traveler picking up a boarding pass.

CODE 

sipClient.register({
  uri: 'sip:username@domain.com',
  username: 'username',
  password: 'password',
  displayName: 'Display Name'
}, {
  server: 'wss://domain.com:443',
  secure: true
});
PLAIN ENGLISH

Tell the softphone to register (sign in) to the server...

The agent's SIP address — like an email address but for phone calls...

The agent's username for authentication...

The agent's password...

The name shown to the other end of the call...

Now the connection settings...

Connect over WSS (secure WebSocket) on port 443...

Yes, use encryption (TLS) — never send calls in plain text

What is NOT in this repo

Kamailio (the SIP router) and the carrier SIP trunk exist in production but live outside this codebase. They are the roads that connect this airport to the rest of the world.
